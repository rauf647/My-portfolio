ASSETS FOLDER - IMAGE PLACEHOLDER INSTRUCTIONS
================================================

This folder should contain the following images for the portfolio:

1. profile.jpg
   - Your professional headshot/photo
   - Recommended size: 400x400px or larger (square aspect ratio)
   - Used in: Hero section and About section

2. project1.jpg
   - Screenshot of Project 1 (Responsive Portfolio Website)
   - Recommended size: 600x400px (3:2 aspect ratio)
   - Used in: Projects section

3. project2.jpg
   - Screenshot of Project 2 (Restaurant Order Management System)
   - Recommended size: 600x400px (3:2 aspect ratio)
   - Used in: Projects section

4. project3.jpg
   - Screenshot of Project 3 (Sales Data Excel-to-Web Application)
   - Recommended size: 600x400px (3:2 aspect ratio)
   - Used in: Projects section

NOTE: Until you add real images, the website will show broken image alt text.
The layout will still work correctly - images will simply not display.

To add images:
1. Place your image files in this folder
2. Make sure the filenames match exactly (profile.jpg, project1.jpg, etc.)
3. Refresh the browser to see the images

TIPS FOR GOOD IMAGES:
- Use JPG or PNG format
- Optimize images for web (keep under 500KB each)
- Use consistent aspect ratios for project screenshots
- Use a professional, well-lit photo for your profile picture
